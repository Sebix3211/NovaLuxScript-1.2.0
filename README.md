intrukcja:

1. Print:
- input:
   Print "Hello World!"
- output:
   Hello World
2. Calc
- input:
  Calc 2 + 3
- output:
   5
3. Set
- input:
  Set x = 2
  Set y = 5
  set z = "YES"
  calc x * y
  print z
- output:
  10
  YES
4. For
- input:
   For x in(1, 5)
       print x
- output:
   1, 2, 3, 4, 5
